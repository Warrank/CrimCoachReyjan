# CrimCoachReyjan

This is the website for Criminology Coach Reyjan Paches. 

On top there is a appbar. In the middel 5 tabs. Switching between tabs goes smooth.
The website contains the following tabs:

# HOME
The home page (./) contains a nice hero and some main information about Reyjan Paches and what he is doing. Also it contains some links to get in contact (link to contact page) Learn more (About page) and to Enroll (Enroll page) 
This page also contains basic information for student. What they can expect and what Reyjan offers

# ABOUT
The about page contains direct information about Reyjan Paches. What he provides and what his Visions and Missions are. Also Why students choose Reyjan Paches.

# ENROLL
This page has some cards with enrollment options and the prices.

# FREE LESSONS
This page contains some links to youtube videos so people can attent free youtube lessons on the page. Also a button to the youtube channel.

# CONTACT
This page contains the contact information. This are 2 cards with herin link to send an Email and a link to the messenger or whatsapp of the 2 contact numbers.


The website self is made in .NET Blazor with MudBlazor for the UI. 
For the styling bootstrap classes are prevered. If no other choice css is used.
